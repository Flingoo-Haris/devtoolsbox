About DevToolbox

DevToolbox is a small collection of 12 developer utilities, built to solve one recurring annoyance: the tools developers reach for most often — a JSON formatter, a JWT decoder, a UUID generator — are usually scattered across different sites, most of which quietly upload whatever you paste to a server.

Every tool here runs entirely client-side in JavaScript. There is no backend that sees your input, no account, and no tracking of what you paste. You can verify this yourself: open your browser's network tab while using any tool and you'll see no request carrying your data anywhere.

All tools

  • JSON Formatter — Paste any JSON, get it validated, pretty-printed or minified instantly. Everything runs locally in your browser — nothing is sent to a server.
  • SQL Formatter — Paste a messy SQL query and get it reformatted with clause-per-line indentation and uppercase keywords.
  • application.properties ↔ YAML Converter — Convert Spring Boot's application.properties to application.yml format, or the other way around.
  • Base64 Encoder / Decoder — Convert plain text to Base64 or decode a Base64 string back to readable text — handles UTF-8 (emoji, accents, non-Latin text) correctly.
  • Unix Timestamp Converter — Convert between Unix epoch timestamps and human-readable dates, both directions, in your local timezone and UTC.
  • UUID Generator — Generate cryptographically random UUIDs (v4) or time-ordered UUIDs (v7) — one at a time or in bulk.
  • Hash Generator — Hash any text with MD5, SHA-1, SHA-256, SHA-384 or SHA-512 — computed locally in your browser using the Web Crypto API (and a built-in MD5 implementation).
  • JWT Decoder — Paste a JSON Web Token to decode its header and payload, and check whether it has expired. Decoding happens locally — your token is never sent anywhere.
  • Regex Tester — Test a regular expression against sample text with live match highlighting, capture groups, and a find-and-replace preview.
  • Cron Expression Parser — Paste a cron expression to get a plain-English explanation and a preview of its next run times. Supports standard 5-field cron and Spring's 6-field (with seconds) format.
  • API Response Mocker & Tester — Two tools in one: generate fake JSON data from a simple field schema, and send a real HTTP request to any endpoint to inspect the response.
  • Text & JSON Diff Checker — Compare two versions of text or JSON side by side, with additions and deletions highlighted line by line.
