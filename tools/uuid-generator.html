UUID Generator

Generate cryptographically random UUIDs (v4) or time-ordered UUIDs (v7) — one at a time or in bulk.

v4v7Bulkcrypto.getRandomValues

How to use the uUID Generator

  1. Choose a UUID version: v4 for fully random IDs, or v7 for time-ordered IDs that sort naturally and index well in databases.
  2. Set how many you need (up to 500 at once) and optional formatting (uppercase, no hyphens).
  3. Click Generate, then Copy all to paste the list straight into code, a database seed script, or test fixtures.
  4. All IDs are generated with your browser's cryptographically secure crypto.getRandomValues API.

Frequently asked questions

What's the difference between UUID v4 and v7?

v4 is fully random (122 random bits), giving no ordering information. v7 embeds a millisecond timestamp in the first bits, so IDs generated later always sort after earlier ones — useful as primary keys because it avoids the index fragmentation random UUIDs cause in databases like MySQL or Postgres.

Are these UUIDs cryptographically secure?

Yes — they're generated with the Web Crypto API's crypto.getRandomValues(), a cryptographically secure random number generator, not Math.random().

Can I use these as primary keys in Spring Boot / JPA entities?

Yes. Map the field as java.util.UUID with @Id, and prefer v7 IDs if you want better B-tree index locality than random v4 values.

Is there a chance of duplicates?

The probability of a UUID v4 collision is astronomically small (roughly 1 in 2.71 quintillion for two random UUIDs to collide), so for practical purposes they're unique.
