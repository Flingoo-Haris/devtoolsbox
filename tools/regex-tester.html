How to use the regex Tester

      
  1. Type a regular expression pattern (JavaScript flavour) and any flags such as g, i or m.
  2. Paste or type your test string — matches highlight live as you type.
  3. Expand the matches panel to see each match's index and any capture groups.
  4. Fill in the replace field to preview a find-and-replace using $1, $2… group references.

      
Frequently asked questions

      
What regex flavour does this use?
JavaScript's native RegExp engine — the same one used in Node.js and browsers. Syntax is very close to PCRE but has a few differences (e.g. no atomic groups, different Unicode property escapes without the u flag).
Why aren't there multiple matches?
Make sure the g (global) flag is set — without it, only the first match is found. This tool adds it automatically for highlighting even if you forget it.
How do I match across multiple lines?
Add the s flag so . matches newlines too, or the m flag so ^/$ match the start/end of each line rather than the whole string.
Can I test lookaheads and lookbehinds?
Yes, JavaScript supports (?=...), (?!...), (?<=...) and (? in modern browsers.
