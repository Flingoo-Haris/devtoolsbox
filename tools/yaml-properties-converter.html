application.properties ↔ YAML Converter

Convert Spring Boot's application.properties to application.yml format, or the other way around.

Spring BootNested keysBoth directions

How to use the application.properties ↔ YAML Converter

  1. Paste your application.properties content on the left and click “Convert to YAML” to get properly nested application.yml output.
  2. Or paste YAML on the right and click “Convert to properties” to flatten it back to dotted keys.
  3. Dotted keys like spring.datasource.url automatically nest under spring: datasource: url: in YAML.
  4. Handles booleans and numbers sensibly, and quotes YAML values that contain special characters.

Frequently asked questions

Does Spring Boot support both formats?

Yes — Spring Boot auto-detects and loads either application.properties or application.yml from src/main/resources; you can use whichever format your team prefers, but not usually both for the same keys.

Does this handle YAML lists / arrays?

This converter targets the common case of nested scalar configuration keys used in Spring Boot config. Complex YAML with lists, anchors or multi-document files may need manual adjustment.

Will comments be preserved?

Comments (lines starting with #) are skipped during conversion rather than preserved, consistent with how Spring's own property loader treats them.

Why did a value get quoted in the YAML output?

Values containing YAML-significant characters like :, #, { or [ are quoted automatically so they aren't misinterpreted as YAML syntax.
