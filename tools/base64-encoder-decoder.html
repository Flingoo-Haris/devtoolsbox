Base64 Encoder / Decoder

Convert plain text to Base64 or decode a Base64 string back to readable text — handles UTF-8 (emoji, accents, non-Latin text) correctly.

EncodeDecodeUTF-8 safe

How to use the base64 Encoder / Decoder

  1. Type or paste plain text on the left, then click “Encode” to get its Base64 representation on the right.
  2. Or paste a Base64 string on the right and click “Decode” to reveal the original text on the left.
  3. The tool encodes/decodes with UTF-8 first, so emoji, accented characters and non-Latin scripts round-trip correctly.
  4. Use Copy to grab the Base64 value for embedding in a URL, config file, Basic-Auth header or data URI.

Frequently asked questions

What is Base64 used for?

Base64 encodes binary or text data into an ASCII-safe string, commonly used in HTTP Basic Auth headers, email attachments (MIME), data URIs for inline images, and JWT segments.

Why did decoding fail?

Base64 strings must only contain the characters A-Z, a-z, 0-9, +, / and end with 0-2 = padding characters. Whitespace and newlines are stripped automatically, but any other character will cause a decode error.

Is this the same as encryption?

No. Base64 is an encoding, not encryption — anyone can decode it instantly. Never use it to protect secrets.

Does it handle URL-safe Base64 (JWTs)?

This tool encodes standard Base64. For JWT tokens specifically (which use URL-safe Base64), use the dedicated JWT Decoder tool.
