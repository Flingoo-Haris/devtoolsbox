Cron Expression Parser

Paste a cron expression to get a plain-English explanation and a preview of its next run times. Supports standard 5-field cron and Spring's 6-field (with seconds) format.

    How to use the cron Expression Parser

    1. Paste a standard 5-field cron expression (minute hour day month weekday), or a 6-field expression with seconds (used by Spring's @Scheduled(cron=...)).
    2. Click Explain to see a plain-English breakdown of each field.
    3. Scroll to “Next 5 run times” to sanity-check exactly when the schedule will actually fire, in your local timezone.
    4. Supports *, ranges (1-5), steps (*/15), lists (MON,WED,FRI) and month/weekday names.

    Frequently asked questions

    Does this support Spring's 6-field cron format?

    Yes. Spring's @Scheduled(cron = "...") uses six fields (seconds first), while standard Unix/Linux cron uses five (no seconds) — this tool auto-detects which one you've entered based on the field count.

    What does day-of-month OR day-of-week mean?

    In standard cron, if both the day-of-month and day-of-week fields are restricted (not *), the job runs when either condition matches, not both — this tool follows that same rule.

    Can I use names like MON or JAN?

    Yes, weekday names (SUN–SAT) and month names (JAN–DEC) are supported in the day-of-week and month fields, including ranges like MON-FRI.

    Why does it show no upcoming runs?

    That usually means the expression describes a combination that can't occur, e.g. February 30th, or a day-of-month/month combination that never lines up — double check the fields.
