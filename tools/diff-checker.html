How to use the text & JSON Diff Checker

      
  1. Paste the original version on the left and the changed version on the right.
  2. Click Compare to see a unified line-by-line diff — green for additions, red for removals.
  3. For JSON, tick “Normalize as JSON before comparing” so both sides are pretty-printed the same way first — this avoids false differences caused only by whitespace or key order.
  4. Use it to review config changes, compare API responses, or check two versions of a file before merging.

      
Frequently asked questions

      
Does it diff word-by-word or line-by-line?
Line-by-line, using a classic longest-common-subsequence algorithm — the same family of algorithm used by tools like diff and Git.
Why does my JSON show as all different when only one value changed?
That usually means the two sides have different formatting or key order. Enable “Normalize as JSON before comparing” so both are re-serialized with the same indentation before diffing.
Is there a size limit?
No hard limit, but very large inputs (many thousands of lines) may be slow since the comparison runs in your browser's main thread.
Can I use this to compare two API responses?
Yes — paste one response into each box, enable JSON normalization, and Compare to quickly spot which fields differ.
